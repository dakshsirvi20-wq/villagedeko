VillageDeko final build

1. Upload index.html, style.css, app.js, firebase-config.js to GitHub Pages.
2. In Firebase Console > Authentication > Sign-in method, enable Google.
3. In Firebase Console > Firestore Database > Rules, paste firestore.rules from this folder and publish.
4. Add your GitHub Pages domain to Firebase Authentication > Settings > Authorized domains.
5. Photo uploads use the existing ImgBB API key.
