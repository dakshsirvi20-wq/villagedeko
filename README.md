# VillageDeko — Modern Village Listing Form

This build uses the latest VillageDeko base and keeps the existing design/features intact.

## Listing form
The Village Listing form is organised to feed the existing village profile sections:
1. Overview
2. Identity & Media
3. Explore
4. Experiences
5. Ek Din Gaon Mein
6. Food & Food Journey
7. People & Stories
8. Culture
9. Visit Information
10. Stay & Wedding
11. Review

The form includes a selectable India state list, repeatable content rows, separate cover photo, later photos/videos, owner delete action, and responsive modern styling.

The current prototype stores the submitted listing locally in the browser. Firebase/real media storage should be connected later without changing the UI structure.
